# Social Media Platform

A full-stack social media platform developed using HTML, CSS, JavaScript, Node.js and Express.js.

## Features

- Create and display posts
- Like and delete posts
- Responsive user interface
- Node.js and Express.js backend
- REST API structure

## Technologies Used

- HTML
- CSS
- JavaScript
- Node.js
- Express.js

## How to Run

```bash
npm install
npm start
